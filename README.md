## 🌌 About The Project

**Smart Expense Leak Detector** is a Python and Flask-based
web application that helps users record daily expenses,
monitor spending, and identify repeated expenses.

The goal is simple: understand where your money goes
and make smarter financial decisions.

## ✨ Key Features

| Feature | Description |
|---|---|
| 💰 Expense Tracking | Record daily expenses |
| 📊 Spending Summary | View total spending |
| 🗂️ Categories | Organize expenses |
| 🔍 Expense History | Review previous records |
| 🗑️ Delete Expenses | Remove unwanted records |
| 🚨 Leak Detection | Planned spending analysis |

## 🛠️ Technology Stack

- **Backend:** Python, Flask
- **Frontend:** HTML, CSS, JavaScript
- **Database:** SQLite
- **ORM:** Flask-SQLAlchemy

## 🚀 Getting Started

### 1. Clone Repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Open Project

```bash
cd Smart-Expense-Leak-Detector
```

### 3. Install Requirements

```bash
pip install -r requirements.txt
```

### 4. Run Application

```bash
python app.py
```

### 5. Open Browser

```text
http://127.0.0.1:5000
```
